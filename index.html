What this project demonstrates

Practical data engineering, not just syntax.

01

Distributed thinking

Transformations remain lazy until actions execute, so pipeline structure and repeated actions matter.

02

Business-aware cleaning

Deduplication uses a pharmaceutical business key instead of dropping arbitrary duplicate rows.

03

Defensive analytics

ANSI-safe arithmetic keeps invalid denominator cases visible without terminating the workload.

04

Portable design

The transformation core is independent from local and AWS Glue execution details.
